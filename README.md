One-line roast of a smart fridge that refuses to open after midnight.

## Entry

> My fridge locks at midnight like it's guarding state secrets — the only classified thing in there is last Tuesday's curry.

## How it works

`main.py` (Python 3 standard library only) writes the roast to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
It asserts the line stays inside the gate: 1–200 characters, not only
whitespace.

## Run

```sh
python3 main.py
```
